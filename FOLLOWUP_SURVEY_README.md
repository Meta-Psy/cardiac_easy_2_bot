**Файл:** `bot/database/models.py` (строки 397-502)

## Установка

### Шаг 1: Применить миграцию базы данных

```bash
python apply_migration.py
```

Эта команда создаст две новые таблицы:
- `followup_surveys` - для хранения ответов
- `followup_status` - для отслеживания статуса

### Шаг 2: Убедиться, что методичка на месте

Проверьте наличие файла:
```
materials/Методичка ЗОЖ.pdf
```

Если файла нет, добавьте его в папку `materials/`.

### Шаг 3: Запустить бота

```bash
python bot/main.py
```

## Использование

### Для администратора:

1. Откройте бота и войдите в админ-панель (команда `/admin`)
2. Выберите **"Рассылки"**
3. Нажмите **"📅 РАССЫЛКА ОПРОСА 3+ МЕСЯЦА (ТОЧКА 3)"**
4. Просмотрите статистику (сколько пользователей получат сообщение)
5. Подтвердите рассылку кнопкой **"✅ ЗАПУСТИТЬ РАССЫЛКУ"**

### Для пользователей:

1. Получают сообщение с кнопкой **"Начать опрос"**
2. Отвечают на 13 вопросов
3. После завершения получают методичку ЗОЖ

## Структура опроса (13 вопросов)

### Вопросы 1-6: Обращение к врачу
1. **Обращались ли к врачу?** (1 вариант)
2. **К какому врачу обращались?** (до 2 вариантов) - *пропускается если не обращались*
3. **Отношение врача** (1 вариант) - *пропускается если не обращались*
4. **Что было сделано на приеме?** (множественный выбор) - *пропускается если не обращались*
5. **Серьезность врача** (шкала 1-10) - *пропускается если не обращались*
6. **Следование рекомендациям** (1 вариант) - *пропускается если не обращались*
   - 6.1. **Что мешает?** (текст) - если не полностью соблюдают

### Вопросы 7-9: Действия и трудности
7. **Шаги по снижению рисков** (множественный выбор)
8. **Стабильность изменений** (шкала 0-10)
9. **Трудности** (множественный выбор)

### Вопросы 10-13: Отношение и потребности
10. **Изменение отношения к профилактике** (1 вариант)
11. **Уверенность в понимании** (шкала 0-10)
12. **Потребность в дополнительной информации** (множественный выбор)
13. **Главное изменение** (текст)

## Техническая информация

### База данных
- Тип: SQLite
- Таблицы: `followup_surveys`, `followup_status`
- Индексы: созданы для `telegram_id`

### FSM состояния
Используется 14 состояний FSM (FollowUpSurveyStates):
- question_1 до question_13
- question_6_barriers (дополнительный вопрос)

### Callback данные
Префиксы:
- `fq1_` до `fq13_` - ответы на вопросы
- `start_followup_survey` - начало опроса

## Troubleshooting

### Ошибка: "Файл методички не найден"
**Решение:** Убедитесь, что файл `materials/Методичка ЗОЖ.pdf` существует

### Ошибка: "Таблицы не найдены"
**Решение:** Запустите `python apply_migration.py`

### Сообщения не отправляются
**Решение:** Проверьте логи, убедитесь что у пользователей `registration_completed = True`

### Пользователи не получают методичку
**Решение:** Проверьте путь к файлу и права доступа
